1. **Mobile-First:** Бездоганний вигляд на екранах 320–430 px, повна відсутність горизонтального скролу, клікабельні зони від 44×44 px.
2. **Семантика та доступність:** Відповідність контрастності тексту вимогам WCAG AA / AAA, чіткий фокус клавіатури (`:focus-visible`).
3. **Чисті технології:** Реалізація виключно на семантичному HTML5 та чистому CSS3 (CSS Variables, Flexbox, Grid) без сторонніх бібліотек.
4. **Підтримка мови:** Шрифти з повною підтримкою польської діакритики (`ą, ć, ę, ł, ń, ó, ś, ź, ż`).

# КОНЦЕПЦІЯ A: DARK PREMIUM (Класичний преміальний барбершоп)

## 1. Загальний стиль
* **Візуальний характер:** Глибока темна атмосфера, вишуканий теплий акцент античного золота/бронзи, відчуття дорогого чоловічого клубу, шкіряних крісел, темного дерева та сталевих інструментів.
* **Емоція:** Спокій, стабільність, респектабельність, бездоганна якість і впевненість.
* **Чим відрізняється:** Традиційна атмосфера висококласного барбершопу, де колірні акценти підкреслюють статусність закладу без неонової строкатості.

## 2. Кольорова палітра
* **Основний фон (Background):** `#111111` (глибокий вугільно-чорний)
* **Поверхні карток / блоків (Surface):** `#1A1A1A` (темний графіт для візуального підняття блоків)
* **Піднята поверхня / ховери (Surface Light):** `#242424` (м'яке підсвічування інтерактивних карток)
* **Основний текст (Text Primary):** `#F5F2EB` (теплий шовково-білий; контраст до фону > 14.5:1 — WCAG AAA)
* **Другорядний текст (Text Muted):** `#A8A39D` (благородний теплий сірий; контраст > 6.8:1 — WCAG AA)
* **Акцентний колір (Accent / Gold):** `#C5A059` (тепла антична бронза/золото)
* **Кнопка Primary (CTA Button):** Фон `#C5A059`, текст `#111111` (контраст > 8.5:1 — WCAG AAA)
* **Кнопка Secondary:** Прозора з рамкою `#C5A059`, текст `#F5F2EB`
* **Рамки й роздільники (Border):** `#2E2C29` (стримані графітово-бронзові лінії)

## 3. Типографіка
* **Заголовки (Headings):** `Montserrat` або `Syne` (жирне накреслення 700–800, величава геометрія, міцний чоловічий характер, 100% підтримка польських літер).
* **Основний текст (Body):** `Inter` або `Plus Jakarta Sans` (400–500, бездоганна читабельність на мобільних пристроях навіть при дрібному кеглі).
* **Принципи розмірів (Responsive Type Scale):**
  * H1: `clamp(2rem, 5vw + 1rem, 3.25rem)` (32px на мобільному → 52px на десктопі)
  * H2: `clamp(1.5rem, 3vw + 1rem, 2.25rem)` (24px на мобільному → 36px на десктопі)
  * Body: `1rem` (16px), line-height: `1.6`

## 4. Header
* **Логотип:** Зліва. Текстовий напис `BLACKLINE BARBER` із невеликим золотистим акцентним знаком або точкою.
* **Навігація (десктоп):** По центру/справа. Текстові посилання з ніжним золотистим підкресленням при наведенні.
* **Кнопка запису:** Заповнена золота кнопка `Umów wizytę` справа в хедері.
* **Мобільна поведінка:** Sticky-хедер із напівпрозорим фоном `#111111EE` та блюром `backdrop-filter: blur(8px)`. Гамбургер-іконка відкриває повноекранне мобільне меню з великими та зручними пунктами.

## 5. Hero
* **Компактний H1:**  
  `BLACKLINE BARBER`  
  *Підзаголовок:* `Męski styl. Bezkompromisowa precyzja.`
* **Композиція на десктопі:** Двоколонковий макет. Зліва — надзаголовок, компактний H1, 2 абзаци виразного тексту та кнопки дій в один рядок. Справа — вертикальне атмосферне фото барбера в шкіряному фартусі (пропорція 3:4) з тонкою золотисто-графітовою рамкою та легкою тінзю.
* **Композиція на мобільному:** Текстовий блок угорі, кнопки одна під одною (на всю ширину екрана), а під кнопками — кадрове фото робочого процесу, плавно розмите в темний фон унизу.

## 6. Інші секції
* **O nas:** Текстовий блок із 3 абзацами ліворуч, праворуч — 3 темні картки ключових цінностей (`Precyzja geometrii`, `Spokojna przestrzeń`, `Najwyższa jakość kosmetyków`) із золотими маркерами.
* **Usługi i cennik:** Класичний преміальний список послуг. Кожна послуга — це елегантний горизонтальний блок із назвою, описом та золотавою ціною `od 70 zł`, відокремленою пунктирною або тонкою лінією.
* **Galeria:** Рівномірна сітка (2 колонки на мобільному, 3–4 на десктопі) з темними 1px контурами між картками.
* **Kontakt:** 3 картки з адресою, годинами та телефоном на фоні `#1A1A1A` з графітовими рамками.
* **Фінальний CTA:** Контрастний темний блок із делікатним золотистим радіальним підсвічуванням по центру та великою кнопкою `Umów wizytę`.
* **Footer:** Текстовий логотип, горизонтальна навігація, юридична демо-примітка з контрастністю не менше 4.5:1.

## 7. Мобільний дизайн (360–390 px)
* Затишний інтерфейс преміального додатка.
* Кнопки мають комфортну висоту 48px і займають повну ширину для легкого натискання великим пальцем однієї руки.
* Відступи з боків екрана: 16–20px.

## 8. Фотографії
* Кінематографічні знімки з глибокими тінями (стиль chiaroscuro), тепле бічне світло, деталі стрижки крупним планом, шкіра, полірована сталь ножиць.

## 9. Анімації
* М'яка зміна прозорості та кольору кнопок (hover transition: `background-color 200ms ease`, `transform: translateY(-2px)`).
* Плавне розкриття мобільного меню (`transition: opacity 250ms ease`).
* Повна підтримка `@media (prefers-reduced-motion: reduce)`.

## 10. Переваги та недоліки
* **Переваги:**
  1. Абсолютно впізнаваний, перевірений і найбільш затребуваний стиль для барбершопів у Польщі.
  2. Бездоганна контрастність і легкість проходження тестів доступності (WCAG AAA).
  3. Швидка та надійна реалізація на чистому CSS без крихких прийомів.
* **Недоліки:**
  1. Традиційність (багато барбершопів обирають темне золото).
  2. Вимагає якісних фотографій саме в темній тональності.
  3. Потребує суворого дотримання балансу золотого кольору, щоб уникнути надмірної строкатості.
* **Складність реалізації:** Низька / Середня (ідеально для легкого підтримуваного коду).
* **Придатність для портфоліо:** **9.5 / 10** — виглядає дорого, професійно та комерційно зріло.

# КОНЦЕПЦІЯ B: MODERN MINIMAL (Монохромний індустріальний хай-енд)

## 1. Загальний стиль
* **Візуальний характер:** Сучасний урбаністичний мінімалізм, індустріальний лофт, монохромна графіка, строга модульна сітка у швейцарському стилі.
* **Емоція:** Прогресивність, дисципліна, хірургічна точність ліній, безкомпромісний модерн великого міста (Варшава, Берлін).
* **Чим відрізняється:** Повна відмова від золота й класичного декору на користь висококонтрастної чорно-білої естетики, сталі, матового титану та чистої типографіки.

## 2. Кольорова палітра
* **Основний фон (Background):** `#0C0D0E` (глибокий холодний антрацит)
* **Поверхні блоків (Surface):** `#141619` (темно-сланцевий)
* **Піднята поверхня (Surface Light):** `#1E2126` (матовий графіт)
* **Основний текст (Text Primary):** `#FFFFFF` (абсолютно чистий білий; максимальний контраст > 18:1)
* **Другорядний текст (Text Muted):** `#8E95A0` (холодний нейтрально-сірий; контраст > 5.5:1)
* **Акцентний колір (Accent / Steel):** `#E2E8F0` (срібляста сталь) / контрастні білі маркери
* **Кнопка Primary (CTA Button):** Фон `#FFFFFF`, текст `#0C0D0E` (максимальний графічний контраст)
* **Кнопка Secondary:** Чорна із тонкою білою рамкою `#FFFFFF`, текст `#FFFFFF`
* **Рамки й сітка (Border):** `#22262C` (технічні індустріальні лінії товщиною 1px)

## 3. Типографіка
* **Заголовки (Headings):** `Space Grotesk` або `Cabinet Grotesk` або `Manrope` (технічний, сучасний, злегка розширений або щільний геометричний гротеск).
* **Основний текст (Body):** `Inter` (нейтральний, стандартизований, технологічний).
* **Індекси та бейджі:** Моноширинний шрифт для номерів секцій: `[01]`, `[02]`, `// OFFER`.
* **Принципи розмірів:**
  * H1: `clamp(2.25rem, 6vw, 3.75rem)` (великий монохромний акцент)
  * H2: `clamp(1.5rem, 4vw, 2.5rem)`
  * Body: `1rem` (16px)

## 4. Header
* **Логотип:** Текстовий логотип з технічним штрихом: `BLACKLINE // BARBER`.
* **Навігація:** Монохромні пункти з індексами: `01. O nas`, `02. Usługi`, `03. Galeria`, `04. Kontakt`.
* **Кнопка запису:** Строга прямокутна кнопка з мінімальним заокругленням (`border-radius: 2px`).
* **Мобільна поведінка:** Мінімалістичний хедер, при відкритті меню з'являється чіткий модульний список із нумерацією.

## 5. Hero
* **Компактний H1:**  
  `BLACKLINE BARBER`  
  *Слоган:* `Precyzja formy. Nowoczesne rzemiosło.`
* **Композиція на десктопі:** Модульна сітка. Зліва великий монохромний заголовок та індекс `// 01 HERO`, праворуч чітко кадроване фото з високим контрастом у прямокутній індустріальній рамці.
* **Композиція на мобільному:** Масивний білий заголовок, короткий маніфест, біла кнопка на всю ширину, під нею — чітке графічне фото з різкими кутами.

## 6. Інші секції
* **O nas:** Модульний блок у стилі Bento Grid: одна велика темна картка з текстом і дві менші картки з геометричними ілюстраціями чи цифрами.
* **Usługi i cennik:** Карткова система з гострими кутами та тонкими рамками 1px. Кожна послуга має технічний префікс `[USŁUGA_01]`, чіткий білий цінник.
* **Galeria:** Асиметрична чорно-біла або монохромна сітка з чітким ритмом відступів (gap: 12px).
* **Kontakt:** Мінімалістична таблиця даних: параметри зліва, значення праворуч, кнопка з ефектом інверсії.
* **Фінальний CTA:** Лаконічна плашка з чітким білим закликом і прямокутною кнопкою.
* **Footer:** Технічний футер із моноширинними написами: статус сайту `STATUS: DEMO_MODE`, координати, копірайт.

## 7. Мобільний дизайн (360–390 px)
* Відчуття швидкого, високотехнологічного інтерфейсу без декоративних надлишків.
* Строгі прямокутні форми, відсутність «заокруглених хмаринок».

## 8. Фотографії
* Контрастні чорно-білі фотографії або сильно знебарвлені (desaturated) знімки з акцентом на геометрію ліній фейду, бритву та сталь.

## 9. Анімації
* Миттєві та різкі переходи (120–150ms cubic-bezier), чітка інверсія кольору: біла кнопка при наведенні стає чорною з білою рамкою.

## 10. Переваги та недоліки
* **Переваги:**
  1. Виглядає ультрасучасно, виділяється серед типових «золотих» шаблонів.
  2. Максимально чітка структура сітки та висока швидкість завантаження.
  3. Чорно-біла палітра полегшує пошук та стилізацію фотографій.
* **Недоліки:**
  1. Може здатися дещо «холодним» або надто строгим для традиційних клієнтів.
  2. Вимагає бездоганного відчуття типографіки, інакше виглядатиме пусто.
  3. Відсутність теплого кольору може зменшити відчуття затишку закладу.
* **Складність реалізації:** Середня (вимагає точного підбору шрифтових розмірів і відступів).
* **Придатність для портфоліо:** **8.5 / 10** — чудово показує смак у сучасній вебтипографіці.

# КОНЦЕПЦІЯ C: EDITORIAL BARBER (Стиль глянцевого чоловічого журналу)

* **Емоція:** Творчість, естетична насолода, затишок закритого джентльменського клубу, культура slow life.
* **Чим відрізняється:** Використання витонченої антикви (Serif) у заголовках у поєднанні з теплими відтінками теракоти, міді та кави.

* **Основний фон (Background):** `#141312` (дуже глибокий кавово-вугільний)

* **Навігація:** Розріджені літери (letter-spacing: 0.12em, uppercase), делікатні крапки між пунктами.
* **Кнопка запису:** Елегантна капсульна кнопка (pill shape, `border-radius: 999px`).
* **Мобільна поведінка:** М'яка шторка з великими витонченими заголовками меню курсивом.

* **Фінальний CTA:** Формат запрошення: «Rezerwacja terminu», витончений шрифт, овальна кнопка.
* **Footer:** Класична журнальна підвальна частина з розлогим копірайтом і посиланнями.

* Відчуття гортання цифрового лукбука преміум-бренду на екрані смартфона.
* М'які радіуси заокруглень, повітряні відступи.

## 8. Фотографії
* Теплі плівкові відтінки, природне лампове освітлення, живі емоції, акцент на атмосферу та людей, а не лише на геометрію стрижки.

## 9. Анімації
* Плавні та довші переходи (250–350ms ease-out), витончене підкреслення тексту тонкою лінією від центру до країв.

## 10. Переваги та недоліки
* **Переваги:**
  1. Висока художня цінність та унікальність; виглядає як дорогий лайфстайл-бренд.
  2. Створює відчуття максимального комфорту та затишку.
  3. Дуже ефектно презентує портфоліо як дизайнерську роботу.
* **Недоліки:**
  1. Шрифти із засічками (Serif) складніше адаптувати під дуже вузькі екрани (320 px) без розривів слів.
  2. Вимагає складнішого підбору фотографій у єдиному плівково-теплому стилі.
  3. Дещо складніша реалізація на чистому CSS, щоб зберегти редакційний баланс.
* **Складність реалізації:** Висока (потребує тонкої роботи з кернінгом і розмірами антикви).
* **Придатність для портфоліо:** **8.5 / 10** — красиво, але ризиковано для першого проєкту новачка.

# РЕКОМЕНДАЦІЯ ТА ОБҐРУНТУВАННЯ

### Рекомендований вибір: **КОНЦЕПЦІЯ A (DARK PREMIUM)**

**Чому саме Концепція A є найкращим рішенням для BLACKLINE BARBER:**

1. **Комерційна переконливість для польського ринку:**  
   Поєднання глибокого темного фону `#111111` із благородним золотисто-бронзовим акцентом `#C5A059` — це стандарт сприйняття преміального барбершопу як серед клієнтів у Польщі, так і серед власників бізнесу. Будь-який барбер чи салон, дивлячись на такий сайт у вашому портфоліо, одразу скаже: *«Це саме те, що потрібно моєму закладу»*.

2. **Ідеальна технічна надійність (HTML5 + чистий CSS3):**  
   Концепція A не вимагає складних або ненадійних CSS-властивостей. Вона будується на класичних змінних (`var(--color-accent)`), Flexbox та Grid. Її легко написати чисто, валідно та зрозуміло для новачка, уникаючи сторонніх бібліотек.

3. **Гарантія доступності (Accessibility / Lighthouse ≥ 90):**  
   Контраст білого тексту на темному тлі складає понад 14:1, а чорного тексту на золотій кнопці — 8.5:1. Це гарантує найвищий рівень доступності без жодних зауважень автоматичних аудитів.

4. **Безпечність мобільної адаптації:**  
   Гротескні шрифти (`Montserrat`/`Inter`) не ламаються на вузьких екранах 320–360 px, не вимагають складного перенесення складів і виглядають чітко на будь-якому смартфоні.
