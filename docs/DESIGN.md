## 1. Візуальний стиль і філософія

### 1.1. Концепція синтезу (Dark Premium + Modern Minimal)
Проєкт базується на концепції **Dark Premium**, доповненій дисципліною та чистотою **Modern Minimal**:
* **Преміальна темна база:** Глибокі вугільні та графітові фони створюють атмосферу спокою, чоловічої впевненості та дорогого простору.
* **Сучасний мінімалізм:** Відмова від «важких» декоративних вензелів, псевдоретро-рамок і надмірного золота. Простір дихає завдяки щедрим відступам, строгій модульній сітці та впевненій типографіці.
* **Помірний шляхетний акцент:** Античне золото (`#C5A059`) використовується **точково й функціонально** — для головних кнопок дії, активних станів та акцентних маркерів. Воно привертає погляд до конверсійних точок, а не засліплює відвідувача.
* **Людяність і якість:** Великі атмосферні фотографії без візуального сміття демонструють майстерність, текстуру матеріалів (шкіра, метал, дерево) та точність ліній.

### 1.2. Чого ми категорично уникаємо (Anti-Patterns)
1. **Золотого перенасичення:** Заборонено робити золотими всі рамки, іконки, лінії та підзаголовки. Золото — це фокус уваги, а не фонова заливка.
2. **Неонових і градієнтних надмірностей:** Ніяких яскравих неонових контурів, радіальних райдужних градієнтів чи глянцевих 3D-відблисків.
3. **Візуального хаосу:** Ніяких випадкових відступів, плаваючих розмірів шрифтів чи неструктурованих карток.
4. **Важких декоративних елементів:** Жодних громіздких візерункових рамок, штучних текстур цегли чи дерева у CSS. Усі текстури приходять через якісні фотографії.

## 2. Кольорова система (Color Tokens)

### 2.1. Палітра CSS Custom Properties
```css
:root {
  /* Основні фони та поверхні */
  --color-bg: #111111;            /* Головний фон сторінки (глибокий вугільний) */
  --color-surface: #1A1A1A;       /* Фон карток, блоків, мобільного меню (темний графіт) */
  --color-surface-hover: #222222; /* Стан наведення для інтерактивних поверхонь */
  --color-surface-raised: #282828;/* Підняті елементи (модалки, бейджі) */

  /* Текстові контрасти */
  --color-text-primary: #F5F2EB;  /* Основний текст, H1, H2, H3 (теплий молочно-білий) */
  --color-text-muted: #A8A39D;    /* Другорядний текст, описи, метадані (благородний сірий) */
  --color-text-inverse: #111111;  /* Текст на золотих кнопках та світлих мітках */

  /* Акцентний колір (Античне золото / Бронза) */
  --color-accent: #C5A059;        /* Теплий бронзово-золотий акцент */
  --color-accent-hover: #D4B26F;  /* Висвітлене золото при hover */
  --color-accent-active: #B59049; /* Глибше золото при active */

  /* Конструктивні рамки та роздільники */
  --color-border: #2E2C29;        /* Тонкі лінії роздільників і контури карток (1px) */
  --color-border-focus: #C5A059;  /* Рамка фокусу для доступності клавіатури */

  /* Напівпрозорі функціональні заливки */
  --color-overlay-bg: rgba(17, 17, 17, 0.85); /* Затемнення для модалок / бекдропу */
  --color-header-blur: rgba(17, 17, 17, 0.92); /* Напівпрозорий sticky header */
}
```

### 2.2. Математична перевірка контрастності (WCAG 2.1)
Усі комбінації перевірено за офіційною формулою відносної яскравості:
* **Основний текст (`#F5F2EB`) на фоні (`#111111`):**  
  Контрастність **16.9 : 1** (норма WCAG AAA — від 7.0:1). Найвища читабельність.
* **Основний текст (`#F5F2EB`) на поверхні карток (`#1A1A1A`):**  
  Контрастність **15.6 : 1** (норма WCAG AAA).
* **Другорядний текст (`#A8A39D`) на фоні (`#111111`):**  
  Контрастність **7.5 : 1** (перевершує навіть суворий рівень AAA 7.0:1).
* **Другорядний текст (`#A8A39D`) на поверхні карток (`#1A1A1A`):**  
  Контрастність **6.9 : 1** (перевершує рівень AA 4.5:1, комфортно для очей).
* **Текст кнопки (`#111111`) на золотому фоні (`#C5A059`):**  
  Контрастність **7.6 : 1** (повна відповідність WCAG AAA). Текст залишається чітким та різким.
* **Золотий акцент (`#C5A059`) на темному фоні (`#111111`):**  
  Контрастність **7.6 : 1** (ідеально для акцентних слів і цін).

### 2.3. Правила використання кольорів
1. **Фон `#111111`:** Використовується для загального полотна сторінки. Створює відчуття цілісності без смугастості секцій.
2. **Поверхня `#1A1A1A`:** Використовується для ізольованих інформаційних модулів: карток цінностей в «O nas», карток контактів, поля модального вікна та розгорнутого мобільного меню.
3. **Золото `#C5A059`:** Дозволено лише для:
   - фону головної кнопки CTA (`Umów wizytę`);
   - цін послуг (`od 70 zł`);
   - маленьких надзаголовків (Eyebrow);
   - індикаторів фокусу (`:focus-visible`);
   - делікатних ліній активних пунктів меню.
   *Заборонено:* писати золотом довгі абзаци тексту чи робити золотими всі рамки блоків.
4. **Рамки `#2E2C29`:** Строго товщиною `1px`. Служать для архітектурного розмежування карток та секцій, не привертаючи зайвої уваги.

## 3. Типографіка

### 3.1. Шрифтова пара
Для збереження високої швидкості завантаження та виключення перевантаження Dell (8 GB RAM) використовується рівно **дві шрифтові сім'ї**:
1. **Заголовки (Headings & Brand):** `Montserrat` (вага: `600 SemiBold` та `700 Bold`).
   * *Характер:* Геометричний, стабільний, сучасний гротеск із виразною архітектурною формою. Бездоганна підтримка польських діакритичних знаків (`ą, ć, ę, ł, ń, ó, ś, ź, ż`).
   * *Fallback:* `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`.

## 4. Система відступів і сітка (Spacing System)

### 4.1. Базовий модуль: 4px / 8px
Всі відступи базуються на кратності 4px та 8px:
* `var(--space-2xs)`: `4px`
* `var(--space-xs)`: `8px`
* `var(--space-sm)`: `12px`
* `var(--space-md)`: `16px`
* `var(--space-lg)`: `24px`
* `var(--space-xl)`: `32px`
* `var(--space-2xl)`: `48px`
* `var(--space-3xl)`: `64px`
* `var(--space-4xl)`: `96px`
* `var(--space-5xl)`: `120px`

### 4.2. Контейнер та адаптивні поля (Layout Margins)
* **Максимальна ширина контенту (`max-width`):** `1200px`.
* **Горизонтальні відступи безпечної зони (`padding-inline` контейнера):**
  * Смартфон (320–430 px): `16px` (на 320 px) / `20px` (на 360–430 px).
  * Планшет (768 px): `32px`.
  * Десктоп (1024–1440 px): `40px` (контейнер центрується через `margin-inline: auto`).

### 4.3. Вертикальний ритм секцій
* **Відстань між секціями (`section padding`):**
  * Мобільні пристрої: `padding-block: 64px` (або `var(--space-3xl)`).
  * Десктоп: `padding-block: 96px – 112px` (або `var(--space-4xl)`).
* **Відстань від заголовка секції до контенту:** `var(--space-2xl)` (`48px` на десктопі, `32px` на мобільному).
* **Внутрішні відступи карток (`card padding`):**
  * Смартфон: `20px`.
  * Десктоп: `28px – 32px`.

## 5. Header (Шапка сайту)

### 5.1. Композиція та геометрія
* **Висота хедера:** `72px` на десктопі, `64px` на мобільному.
* **Позиціонування:** `sticky; top: 0; z-index: 100;`.
* **Фон:** `var(--color-header-blur)` з ефектом `backdrop-filter: blur(10px)`.
* **Нижня межа:** тонка 1px лінія `border-bottom: 1px solid var(--color-border)`.

### 5.2. Елементи
1. **Логотип (зліва):**
   * Текстовий знак: `BLACKLINE BARBER`. Шрифт `Montserrat`, `700`, `18px`, `letter-spacing: +0.06em`.
   * Делікатна золота крапка після слова: `BLACKLINE BARBER<span style="color: var(--color-accent)">.</span>`
2. **Головна навігація (по центру на десктопі):**
   * Пункти: `O nas`, `Usługi`, `Galeria`, `Kontakt`.
   * Шрифт `Inter`, `500`, `14px`, колір `var(--color-text-muted)`.
   * При наведенні: колір змінюється на `var(--color-text-primary)`, внизу з'являється тонка золота лінія (2px) із плавною появою.
3. **Кнопка запису (справа):**
   * Компактна кнопка `Umów wizytę`. На десктопі — висота 40px, padding: `0 20px`. Золотий фон, темний текст.
4. **Мобільне меню (Button Toggle):**
   * Кнопка гамбургера розміром 44×44 px із трьома тонкими лініями (2px) кольору `#F5F2EB`.
   * Атрибути доступності: `aria-expanded="false"`, `aria-label="Otwórz menu nawigacji"`.
   * При відкритті: лінії трансформуються в хрестик за 200ms.
   * Випадаюче меню: повноекранна шторка на фоні `var(--color-surface)` з великими пунктами (шрифт 20px, відступ 20px між пунктами) та великою кнопкою `Umów wizytę` внизу.

* **Ліва колонка (Текст і CTA):**
  * Надзаголовок → H1 → Підзаголовок.
  * Блок кнопок (в один рядок, `gap: 16px`):
    - Primary CTA: `Umów wizytę` (золота кнопка).
    - Secondary CTA: `Zobacz usługi` (прозора кнопка з тонкою графітовою рамкою 1px, яка при ховері стає золотою).

### 6.3. Композиція на смартфоні (360–390 px)
* **Порядок відображення (Vertical Stack):**
  1. Надзаголовок (Eyebrow)
  2. Компактний H1 (32px, 2–3 короткі рядки)
  3. Підзаголовок (15px, 3 рядки)
  4. Кнопки CTA (одна під одною, кожна на повну ширину `width: 100%`, висота 48px)
  5. Фотографія Hero (розміщується нижче кнопок, співвідношення 16:10 або 4:3, щоб не витісняти заклики до дії за перший екран).

### 8.1. Концепція списку-меню (Modern Clean Rows)
Замість важких громіздких карток, які перевантажують мобільний екран, використовується витончена та зручна система рядків преміум-меню:
* **Окремий елемент послуги (Service Row):**
  * Верхній рядок: Назва послуги (`Strzyżenie męskie`) ліворуч — шрифтом `Montserrat 600`, а праворуч — чітка золота ціна (`od 70 zł`, шрифт 18–20px, `color: var(--color-accent)`).
  * Роздільник між назвою та ціною: делікатна пунктирна або приглушена тонка лінія `var(--color-border)`.
  * Нижній рядок: Професійний опис послуги дрібнішим шрифтом (14px, колір `var(--color-text-muted)`).
  * Час послуги (Badge): Маленька стримана мітка поруч із назвою: `45 min`.
* **Роздільники:** Між послугами — тонка суцільна лінія 1px `var(--color-border)`.
* **Позначення демонстраційного статусу (Disclaimer):**
  * Під списком послуг курсивний текст 13px: `* Ceny oraz czasy trwania usług mają charakter orientacyjny i demonstracyjny.`
* **CTA секції:** По центру під списком кнопка `Zarezerwuj wizytę`.

Оскільки заклад є навчальним і ми суворо дотримуємося правила **не створювати фейкових контактів**, секція оформлюється чесно й сучасно:
* **Заголовок:** `Skontaktuj się z nami`.
* **Сітка контактних блоків (3 картки):**
  1. **Lokalizacja:** `[Ulica i numer]` / `[Miasto — do uzupełnienia dla klienta]`
  2. **Godziny otwarcia:** `Pn–Pt: [09:00–20:00]` / `Sob: [09:00–16:00]` / `Nd: Zamknięte`
  3. **Bezpośredni kontakt:** `Tel: [+48 XXX XXX XXX]` / `E-mail: [kontakt@...]`
* **Оформлення карток:**
  * Фон `var(--color-surface)`, рамка 1px `var(--color-border)`.
  * Кожна картка містить невелику лаконічну піктограму та текстову мітку золотого кольору.
* **Демо-повідомлення:**
  * Плашка внизу секції з приглушеним бейджем: `To jest szablon demonstracyjny. Rzeczywiste dane kontaktowe oraz interaktywna mapa zostaną skonfigurowane dla konkretnego salonu.`
* **Кнопки дій:**
  * Кнопки `Zadzwoń do nas` та `Jak dojechać` мають демонстраційний статус (клік показує зрозуміле спливаюче пояснення, жодних неробочих `href="#"`).

## 12. Мобільний дизайн і контрольні точки (Responsive Breakpoints)

### 12.1. Контрольні ширини екранів
1. **320 px (Мінімальний екран / iPhone SE 1st gen):**
   * Горизонтальні поля контейнера: `16px`.
   * H1 зменшується до `28–30px`.
   * Кнопки займають 100% ширини з висотою 48px.
   * Жоден рядок ціни чи тексту не ламається і не створює горизонтального скролу (`overflow-x: hidden` на рівні `body`).
2. **360–390 px (Базовий сучасний смартфон — ГОЛОВНИЙ ПРІОРИТЕТ):**
   * Поля контейнера: `20px`.
   * Повна доступність великим пальцем однієї руки (Thumb-zone).
   * Комфортна висота таргетів: мінімум 44×44 px для всіх посилань та кнопок.
3. **430 px (Великі смартфони — Pro Max / Plus):**
   * Збереження мобільної композиції зі збільшеними полями для збереження пропорцій.
4. **768 px (Планшети):**
   * Перехід карток «O nas» у сітку з 2 колонок.
   * Галерея стає 2-колонковою.
5. **1024 px (Ноутбуки):**
   * Розгортання десктопного меню в хедері (мобільна кнопка гамбургера ховається).
   * Hero переходить у 2-колонкову асиметричну сітку.
   * Галерея розгортається на 4 колонки.
6. **1440 px (Широкі екрани):**
   * Контент фіксується на `max-width: 1200px` по центру з гармонійними бічними полями.

## 13. Специфікація компонентів і станів (UI Components)

### 13.1. Primary Button (Головна кнопка)
* **Стиль:** Фон `var(--color-accent)`, текст `var(--color-text-inverse)`. Шрифт `Montserrat 600`, `15px`, `border-radius: 4px`, `border: none`.
* **Hover:** Фон висвітлюється до `var(--color-accent-hover)`, легкий зсув вгору `transform: translateY(-1px)`.
* **Active:** Фон `var(--color-accent-active)`, зсув повертається `transform: translateY(0)`.
* **Focus-visible:** Контур `2px solid #FFFFFF`, зміщення `outline-offset: 3px`.

### 13.2. Secondary Button (Другорядна кнопка)
* **Стиль:** Прозорий фон, текст `var(--color-text-primary)`, рамка `1px solid var(--color-border)`. Заокруглення `4px`.
* **Hover:** Рамка стає `var(--color-accent)`, текст стає золотим `var(--color-accent)`.
* **Focus-visible:** Контур `2px solid var(--color-accent)`, зміщення `3px`.

### 13.3. Інтерактивні посилання навігації
* **Звичайний стан:** Колір `var(--color-text-muted)`.
* **Hover:** Колір `var(--color-text-primary)`.
* **Focus-visible:** Видима рамка фокусу `2px solid var(--color-accent)`.

### 13.4. Модальне вікно / Тост для кнопки Booksy

## 14. Анімації та мікровзаємодії

1. **Тривалість і таймінг:**
   * Усі переходи (transitions) мають тривалість **150ms – 250ms**.
   * Функція плавності: `ease` або `cubic-bezier(0.16, 1, 0.3, 1)`.
2. **Типи анімацій:**
   * Зміна кольору кнопок і посилань при hover.
   * Плавне розкриття мобільного меню (`opacity` та `transform: translateY`).
   * М'яке збільшення фотографій галереї при наведенні курсору на десктопі (`transform: scale(1.03)`).
3. **Доступність (Prefers-Reduced-Motion):**
   ```css
   @media (prefers-reduced-motion: reduce) {
     *, *::before, *::after {
       animation-duration: 0.01ms !important;
       animation-iteration-count: 1 !important;
       transition-duration: 0.01ms !important;
       scroll-behavior: auto !important;
     }
   }
   ```

## 15. Технічні правила реалізації коду

1. **HTML5:**
   * Суворо семантичні теги: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
   * Рівно один `<h1>` на сторінці.
   * Кожне зображення має явні атрибути `width`, `height`, `loading="lazy"` (крім головного hero-зображення) та змістовний `alt` польською мовою.
2. **CSS3:**
   * Тільки чистий CSS без препроцесорів, Tailwind чи Sass.
   * Використання CSS Custom Properties для всіх токенів.
   * `box-sizing: border-box;` для всіх елементів.
   * Верстка на базі `flexbox` та `css grid`.
3. **Vanilla JavaScript:**
   * Лише базові дії: перемикання стану мобільного меню (`aria-expanded`), модальне вікно демо-бронювання, закриття на `Escape`.
   * Жодних сторонніх бібліотек, jQuery чи важких плагінів.
